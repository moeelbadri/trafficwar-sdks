# Security policy

## Supported versions

Security fixes are released for the latest `1.x` version of each SDK.

## Reporting a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/moeelbadri/trafficwar-sdks/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected package and version, reproduction steps, impact, and any
suggested mitigation. Do not include active TrafficWar API keys or customer
event data.

If a key may have been exposed, rotate it immediately in the TrafficWar
control panel.
